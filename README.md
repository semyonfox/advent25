# Advent of Code 2025

Rust solutions for Advent of Code 2025. Because why solve puzzles in a language you already know?

## Run a day

```bash
cargo run --bin day1
```

## Structure

- `src/dayN.rs` — Solution for day N
- `src/main.rs` — Runs all days
